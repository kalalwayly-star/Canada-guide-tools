# Newcomer Guides & Tools

A free website that provides practical guides and useful tools for newcomers in Canada.

## Project Goals

- Help newcomers settle in Canada.
- Provide useful calculators and tools.
- Publish high-quality guides.
- Support English and Arabic.
- Build a fast website without a database.

## Technologies

- HTML5
- CSS3
- JavaScript
- JSON
- GitHub Pages
